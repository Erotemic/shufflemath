# Visualization / presentation roadmap

The Manim deck under `visualizations/` is meant to answer a question that the
Lean theorem ladder alone does not: **how do all of the mathematical models fit
together, and which interfaces do we actually need to formalize?**

## Narrative principle

The deck treats the literature as a set of reusable components:

- Bayer--Diaconis supplies the exact ideal local riffle kernel.
- Fulman and Assaf--Diaconis--Soundararajan supply biased-cut variants.
- Jonasson--Morris supplies correlated-label models for clumpy/dealer shuffles.
- Nestoridi--White supplies the large-deck / Bernoulli--Laplace reduction when
  local packets are perfectly randomized.
- Griffin et al. supplies the unequal-urn spectral setting relevant to 50/49.
- Nestoridi--Priestley--Schmid supplies a neighboring perfect-block-update
  working-set model.
- Sellke--Shi--Wang clarifies how broad cut-size distributions differ from
  clumping and other local dependence.
- Diaconis--Fulman (2023) is the book-length map of the established shuffle
  landscape.

The intended extension is not "a new shuffle." It is a **finite control
problem over several established kernels** where local randomization is finite,
working-set changes are explicit, operations have different physical costs,
and a terminal TV target constrains the schedule.

## Formal interfaces highlighted by the deck

1. **Bernoulli--Laplace interface**
   - symbolic row normalization;
   - hypergeometric stationary law;
   - reversibility;
   - first eigenfunction/eigenvalue;
   - finite schedule-optimality certificates.

2. **GSR interface**
   - inverse binary-label definition;
   - repeated 2-shuffle / `a`-shuffle composition;
   - rising-sequence probability formula;
   - exact finite TV at working-pile sizes 49 and 50.

3. **Composition interface**
   - TV contraction;
   - Dobrushin bounds where useful;
   - heterogeneous-kernel telescoping replacement theorem.

4. **Protocol interface**
   - action semantics (`local-left`, `local-right`, `exchange k`, or symmetric
     variants);
   - additive physical cost;
   - terminal error certificate;
   - bounded optimality certificate generated by an external search program and
     verified in Lean.

5. **Realism interface**
   - biased labels;
   - correlated labels (clumpy/dealer);
   - untouched-tail / chunk models;
   - robust parameter sets measured from a person rather than a single
     "shuffle efficiency" scalar.

This keeps the research program modular: stronger local models can replace GSR
without changing the protocol semantics, and better search algorithms can
replace brute force without changing what Lean verifies.
